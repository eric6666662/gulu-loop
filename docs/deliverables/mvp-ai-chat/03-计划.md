## 风险与前置

1. **前端工程从零起步**（`web/` 只有占位 `dist/index.html`）：任务 1 包含 Vite + Tailwind v4 + `lucide-vue-next` + `vitest` 的搭建，是全部 UI 任务的前置。若 `npm ci` 无 lockfile 需先 `npm install` 生成。
