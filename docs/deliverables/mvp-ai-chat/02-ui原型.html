帮我把之前那版快速排序改成 Go 泛型版本，[]int、[]string 都能直接用。

泛型版要把元素类型和比较函数一起参数化，这样 []int 和 []string 都能用：

func QuickSort[T any](s []T, less func(a, b T) bool) []T {
	if len(s) < 2 {
		return s
	}
	pivot := s[len(s)/2]
	var lo, eq, hi []T
	for _, v := range s {
		switch {
		case less(v, pivot):
			lo = append(lo, v)
		case less(pivot, v):
			hi = append(hi, v)
		default:
			eq = append(eq, v)
		}
	}
	out := append(QuickSort(lo, less), eq...)
	return append(out, QuickSort(hi, less)...)
}

两点值得注意：

  • pivot 取中间元素而不是首元素，已经有序的切片不会退化到 O(n²)。
  • 三个分区里 eq 单独放，重复元素多时比两分区快一截。
