## 4. 残留风险（04-审查报告 未处理项 + 本次新发现）

1. **`conversationTitle` 多余 SELECT**（04-审查 建议改 2，未修）：每次发送多查一次标题。`appendMessage` 可返回标题省掉。非阻塞，性能微优化。
2. **思考内容不渲染**（04-审查 待澄清）：契约带、前端存、UI 不渲染（deferred 折叠面板）。若要渲染需回 `flow-design-ui` 补设计。
3. **thinkingContent 追加未直接单测**（本次新发现）：见 §3 未核对项。契约层已覆盖，前端 append 逻辑同 content 模式但未直接测。
4. **`regenerate` 后 `userMessageId` 会变**（ADR-0017 已知副作用）：前端靠 `meta` 替换本地旧 id。已 e2e 验证，但若后续有代码绕过 `meta` 直接用旧 id 会 400。风险低（已由 `meta` 处理覆盖）。
